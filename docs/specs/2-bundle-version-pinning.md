# Generated folders against a newer cluster: versions recorded, never downgrade, operator kinds checked

Issue: #2 · Status: Implemented · Release: Unreleased

## Summary
A folder generated by an older installer could not be reinstalled on a cluster where the DX Delivery Operator (or
another extra) was upgraded afterwards: it downgraded the operator while its cluster-wide CRDs stayed newer, applied
kinds that no longer existed, and its `--cleanup` deleted nothing when one kind was unknown. The folder now records what
it was generated with, never downgrades an extra, checks the operator kinds before using them, and cleans up by
discovery.

## Current behaviour (before)
- `src/cicd.js` step OP-1 (1-6 in 2.3.0): `kubectl apply` of the CRDs of the pinned version and
  `helm upgrade --install dxop … --version <pinned>`, whatever the cluster runs.
- Step OP-2 (1-7): applies `lab-cicd/dxop-hello.yaml` and waits for its kinds, without checking that they are served.
- `--cleanup`: one `kubectl delete dxpages,dxthemes,…,dxconnections` with `2>/dev/null`: one unknown type cancels it.
- `BUILD-INFO.txt` had the installer version and the third-party charts, `install.sh` only a one-line stamp.

## Specification
- `src/compat.js` (output layer; the engine is untouched, golden test unchanged):
  - `BUNDLE_FORMAT = 2` (1 = folders before this change).
  - Every `install.sh`, `prepare.sh` and `demo.sh`: `BUNDLE_FORMAT`, `INSTALLER_VERSION` and `PINNED_CHARTS` (the
    `helm upgrade --install … --version` of that script) at the top, and two header lines (`generated with`,
    `pinned charts`).
  - `BUILD-INFO.txt`: `bundle.format` after `installer.version`; with the operator, `operator` (chart, version and
    the kinds with their API version that the folder uses).
  - `keepNewer`: a step body that runs only when no newer Helm release of the chart is installed; otherwise it prints
    `<tool> <version> found (namespace <ns>), newer than <pinned> (the version of this folder): kept, not downgraded`.
    Versions compare with `sort -V`. A failing `helm list` counts as "nothing found".
- Used for: the DX Delivery Operator (charts `dx-delivery-operator` and the former `hcl-dx-scriptapp-operator`, in
  every namespace, because its CRDs are cluster-wide; the CRD apply is skipped too), OpenBao, External Secrets
  Operator and Argo CD (their release in the CI/CD namespace).
- `install.sh` with the operator, once the cluster is reachable and before the confirmation: if the cluster runs a
  different operator version:
  - older: a warning that the folder upgrades it;
  - newer and it serves every kind (apiVersion + kind) of the folder: a warning that it is kept;
  - newer and it does not: stop (exit 1) with the installer version, the pinned and found versions, the namespace,
    the missing kinds, and the fix (generate the folder again with the current installer, or uninstall the newer
    operator).
- Step OP-2: the same kinds check right before `kubectl apply -f lab-cicd/dxop-hello.yaml` (it also works when the
  RUNBOOK commands are pasted: `false`, not `exit`).
- `--cleanup`: `kubectl api-resources --api-group=dx.europesip.com --namespaced -o name`, deleted one by one,
  DXConnection last; the known list of the folder if the group is not served.

## Acceptance criteria
- [x] Given a folder of version N-1 and a cluster with the current operator, when `./install.sh` runs, then it keeps
  the newer operator (with a warning), or stops at the start saying which versions differ.
- [x] Given the same situation, when `./install.sh --cleanup` runs, then every operator resource present in the
  cluster is deleted (each kind separately).
- [x] The installation header prints the installer version and the versions the folder expects.
- [x] The golden test still passes.

## Out of scope
- Folders of bundle format 1 (already generated): fixed by hand, see docs/troubleshooting.md.
- Keycloak (raw manifests of the Keycloak operator, not Helm), CloudNativePG and OpenLDAP (part of the base folder).
- Migrating the resources of a folder to renamed kinds automatically.
